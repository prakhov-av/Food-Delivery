# Этап логирование

Изменения:
- RequestLoggingInterceptor больше не сериализует тело запроса, заголовки, cookie, query string или route-параметры.
- Перехватчик пишет только HTTP-метод, шаблон маршрута, контроллер/метод, статус и длительность.
- Ожидаемые HTTP-ошибки пишутся на warn, неожиданные — на error; исходное сообщение исключения не попадает в лог перехватчика.
- maskSensitive стал рекурсивным и нечувствительным к регистру; маскирует ключи, связанные с паролями, токенами, API-ключами, авторизацией и персональными данными.
- ChatService пишет только безопасные метаданные промптов; переключатель CHAT_DEBUG_PROMPTS больше не может включить логирование полного текста.
- Сырые ответы классификатора ИИ больше не включаются в текст исключения.
- GlobalExceptionHandler не пишет в лог stack/message исключения и не возвращает query string в поле path.
- Убраны email и имя пользователя из успешных сообщений UsersService.
- Добавлены тесты на отсутствие утечек в логах перехватчика.
